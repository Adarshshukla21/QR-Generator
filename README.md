# QR Code Generator

A simple and responsive QR Code Generator built using HTML, CSS, and JavaScript.

## 🚀 Features

- Generate QR codes from text
- Generate QR codes from URLs
- Simple and clean user interface
- Responsive design
- Instant QR code generation
- Uses QR Server API

## 🛠️ Technologies Used

- HTML5
- CSS3
- QR Server API
